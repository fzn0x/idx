    About idx

    Indonesian stock market data, free. IHSG, stock prices, holders above 1 % and news, from public sources. No account and no cost.

    As published. Every figure names its source and time. When a source gives no value, idx prints n/a instead of guessing.

    One tool, three ways. Read it on this page and in the terminal, type it on your computer with the CLI, or let an AI agent use it through MCP.

    Open the terminal Read the docs

    Install it

    For developers and terminal users: install the CLI on Linux or macOS, or register the MCP server in Claude Code.

    Install · Linux, macOS 

    curl -fsSL https://raw.githubusercontent.com/fzn0x/idx/main/install.sh | sh

    AI agents · Claude Code 

    claude mcp add idx -- idx mcp

    Notes

    What this tool does and does not do

    Scope. stocks quote · history · profile · financials · earnings · dividends · returns · fundamental · technical · brief · compare · screen · news · sentiment, market overview, broker, bandar detect · screen, ownership import · ticker · entity · changes · foreign and watch, plus mcp, schema, config, cache. Output as a table, -o json, -o jsonl or -o csv. Every command works on IDX tickers such as BBCA; ^JKSE is IHSG.

    Sources. Yahoo Finance for prices, history, profiles, ratios, earnings and statements; MSN Money for a second opinion on ratios and analyst targets, and for the institutions and funds holding a stock (CLI and MCP); IDX's monthly KSEI file for holders above 1 %; KSEI's monthly composition archive from ksei.co.id for local and foreign holders by investor type (CLI and MCP); the exchange's own idx.co.id summaries for foreign flow, member activity, indices and the corporate-action calendar (CLI and MCP: the exchange refuses requests from data centres, this page's host included); Indo Premier for broker summaries, the market-wide broker ranking, foreign flow per stock in rupiah and corporate actions; Kontan and CNBC Indonesia feeds for news; and, opt-in, Stockbit for realtime quotes, history, a live order book, corporate actions and insider and major-holder movements carrying your own Stockbit session (CLI and MCP only, via idx stockbit login). Every response names its provider, fetched_at, and whether it came from cache.

    Provenance over polish. When two sources disagree they are never averaged: the first answers, the second fills blanks, and sources lists who contributed. Yahoo publishes gross margin as 0 for banks; idx publishes null, because it means not applicable.

    Ownership. Since March 2026 KSEI compiles, and IDX publishes monthly, every holder above 1 % of a listed company. The CLI imports the XLSX (or the earlier PDF) into local SQLite with normalised entity names, so who holds more than 1 % of BBCA and what did this fund change last month are one command each. idx.co.id sits behind Cloudflare; the import explains the manual path when a download is refused.

    Heuristics are labelled. The fundamentals verdict, the technical signal and the news sentiment are rule scores. Every rule that fired is listed in plain language, and none of them is advice.

    Offline and free. Responses are cached with per-endpoint lifetimes; --offline serves the cache when the network is gone. No accounts, no keys, no paywall. MIT licence; self-hosting this page is one wrangler deploy.
